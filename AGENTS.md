- **Prefer NOT to edit `blog/themes/next/` directly** — override via `blog/source/_data/next.yml`. Small config-only changes (e.g., menu entries) in `themes/next/_config.yml` are OK when no `_data/` dir exists yet.

- **Do NOT use `npm run` in blog/** — bin symlinks may be broken; use `node node_modules/hexo/bin/hexo` instead
- **Do NOT run `hexo deploy`** — CI handles deployment now
- **Do NOT run genresume.sh inside huaqianlee.github.io/** — run from `resume/` directory

## RESUME WORKFLOW

Resume source lives in `resume/` (sibling of `huaqianlee.github.io/`). Edit markdown, then generate:

```bash
# From resume/ directory:
./genresume.sh              # Generate Chinese resume (HTML + auto-copy)
./genresume.sh en           # Generate English resume
./genresume.sh cn --pdf     # Generate Chinese + PDF (requires Playwright chromium)
```

The script:
1. Converts `resume_*.md` → HTML via Pandoc
2. Copies HTML to `blog/source/` (Hexo serves at `/blog/resume_*.html`)
3. Copies HTML to `astro/public/` (Astro serves at `/resume_*.html`)
4. Optionally generates PDF via Playwright (`--pdf` flag)

Hexo `_config.yml` has `skip_render: ['resume_*.html']` to prevent template processing.

**PDF prerequisite (one-time setup):**
```bash
cd huaqianlee.github.io && npx playwright install chromium
```
